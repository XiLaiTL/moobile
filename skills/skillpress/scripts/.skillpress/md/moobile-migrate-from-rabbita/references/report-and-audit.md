## 五、生成后自查：只在原生上现形的两块

`create` **落盘之后**会读生成物跑一遍 `app-audit.js`，结果进报告 §5 与收尾输出。它报两类洞：

| 洞 | 为什么 web 上看不见 |
|---|---|
| `page-style-unused` —— 源 CSS 的 `body` / `html` 被抽成 `page()`，却没人挂到根上 | 浏览器自带 `body` 样式，而"纸色底 / 衬线族"那几条断言被别的元素满足了 |
| `no-native-scroll` —— 根上没有滚动容器 | RN 的 `View` **不滚动**，而 DOM 自己会滚 |

- 实测的代价：zhouyi-reader 迁到真机后"**滚 30 次、界面纹丝不动**"，而**同一个页面**在 web 判据里
  **45/45**。修法是**两层根容器**：`page()` 挂到最外层，内容再套 `@html.node("scroll", …)`
  （`docs/design/SCAFFOLD.md` §3.7.4.1）。
- ⚠️ 自查**也只是报告**：`page()` 挂哪一层、滚动容器包住哪几块，是**人的决定**。
- 离线门是 `tools/migrate_app_audit.mjs`（真实应用必须干净 + 故意做坏的样本必须被逐条点名）。
